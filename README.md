# Bài 2 Thực hành HTTP Server 

Bước 1: Tạo thư mục dự án

Tạo một thư mục mới có tên nodejs-http.

Mở thư mục bằng Visual Studio Code.

Tạo hai file:

server.js: Chứa mã nguồn tạo máy chủ HTTP.

package.json: Chứa thông tin và cấu hình dự án.
